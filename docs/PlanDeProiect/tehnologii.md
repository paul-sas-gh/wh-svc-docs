Lista și rolul principal al tehnologiilor:

- Java & JVM – limbaj principal, matur, ecosistem bogat.
- Spring Boot + WebFlux – microservicii reactive, performanță ridicată la I/O.
- PostgreSQL – stocare relațională pentru subscripții și metadate.
- Redis – cache, rate limiting, stocare tranzitorie pentru nonce-uri anti-replay.
- RabbitMQ – message broker (event ingestion + dispatch).
- Docker – containerizare pentru medii consistente.
- Kubernetes – orchestrare, scalare automată, rolling updates.
- Prometheus & Grafana – colectare și vizualizare metrici (Micrometer + Actuator).
- ELK Stack (Elasticsearch, Logstash, Kibana) – centralizare și analiză loguri.
- Spring Retry & Resilience4j – pattern-uri de reziliență.
- Spring Cloud Gateway – API Gateway (auth, routing, rate limiting).
- Vault / Secrets Manager – gestionare securizată a secretelor.
- GitHub Actions / Jenkins – CI/CD (build, test, scan securitate, deploy).
